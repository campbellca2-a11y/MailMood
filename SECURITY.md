\# Security Policy



\## Reporting Security Issues



If you discover a security vulnerability in MailMood, please report it privately instead of using the public issue tracker.



Contact: camp5150@outlook.com



Please include:

\- Description of the vulnerability

\- Steps to reproduce (if applicable)

\- Potential impact
